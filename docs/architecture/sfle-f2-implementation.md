## Precision decision and actual implementation

**D-F1.11:** 0.01 logical px pure / 1.0 logical px native; exact tree IDs/order/flex lines. A single Blink LayoutUnit is **1/64 = 0.015625 logical px**, which **exceeds 0.01**. The original fuzz failures were incorrect **border widths** as well as subsequent x positions. Rounding final sanitized boxes is prohibited because it cannot repair an allocation error that already propagates to later children.

Reference oracle, from actual [Chromium CI 38103899275](https://github.com/Neuri-AI/PSX/actions/runs/38103899275): **Playwright 1.63.0**, Chrome for Testing / Chromium Headless Shell **153.0.8010.12**, Playwright build **1243**, Ubuntu x86_64, device-scale-factor 1. `tests/sfle/fixtures/f2_alpha_acceptance.json:chromium_reference` pins the oracle and `test_sfle_chromium_version.py` checks the launched `browser.version` before geometry tests. The Chromium workflow pins `playwright==1.63.0` and runs this mandatory test. Upgrading requires recalculating and reviewing affected DOM fixtures first; it may not silently advance on a dependency upgrade.

**Actual arithmetic, do not overclaim:** Python (`compute_alpha.py`) and Rust (`compute_layout.rs`) apply corresponding 1/64 px quantization to applicable resolved percentages and used main sizes, and `margin_tree.py`/`margin_tree.rs` quantize each relevant placement/translation increment. Explicit percent `flex-basis` is floored to the 1/64 grid *before* the flexible-length loop; percentages on other properties use applicable resolution stages. The flexible-length freeze/allocation loop itself is **f64**, not a full integer-based implementation of Chromium's `LayoutUnit` arithmetic. After §9.7 allocation, both engines model reverse-order distribution of the remaining integer subpixel units using CSS flex-factor weights, before recursively laying out children. The prior matched 100-case seed validated this **restricted algorithm**, not general Blink fixed-point equivalence. **The 19 out-of-sample REDs historically proved prior rounding divergence; all 19 now pass the amended freezing algorithm**. Do not describe both engines as fully emulating Blink until a broader independent oracle verifies the freezing/remainder ties.
