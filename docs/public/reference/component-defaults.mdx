# Portable component defaults

The values below are transcribed from [`psx/core/defaults.py`](https://github.com/Neuri-AI/PSX/blob/18a1cab5d8d6a059170c666313119530a4394b6f/psx/core/defaults.py) and contract declarations in [`psx/core/contracts.py`](https://github.com/Neuri-AI/PSX/blob/18a1cab5d8d6a059170c666313119530a4394b6f/psx/core/contracts.py), pinned to source SHA `18a1cab5d8d6a059170c666313119530a4394b6f`. Not every default applies identically to every native renderer. For per-component restrictions read the source validator and its behavioral tests.

## Notes

- Events are callable properties whose names and payload contracts must be checked against validators and renderer adapters.
- Additional Flex item metadata may apply to child controls; accepted names are defined in `psx/core/props.py`.
- `Grid` and `GridItem` have separate normalized defaults in `psx/core/grid_contract.py` and require Cinnamon geometry; this page does not invent their defaults.
