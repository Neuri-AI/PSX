# Python reference

The reference will be divided into **Everyday APIs** (components, state, markup and applications) and **Advanced APIs** (registries, plugins, native interoperability, lifecycle and public exceptions).

Every published API page must show its actual `psx` import, signature, parameters, return value, errors, lifecycle restrictions, and source/test evidence pinned to a commit.

The detailed pages will be delivered in G4. A public name listed in an audit snapshot is not by itself proof of a supported behavior. See [Component catalog](/components/overview) and [Core concepts](/concepts/overview).
