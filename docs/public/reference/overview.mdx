Velto exposes a small set of application-facing modules which directly re-export Qyro, PSX and Pydux. The root `velto` package exports `VeltoContext` and `__version__`. For UI use `velto.ui`; for state use `velto.state`; for Qyro resources use `velto.runtime`.

The detailed [source-derived API reference](/reference/generated-contracts) is generated from PSX's currently checked-out public symbols and component contracts. Treat its signatures and defaults as declaration evidence, **not** proof of identical behavior on every renderer.

Follow these references in order: [application and hooks](/reference/application-and-state), [component contracts](/reference/component-contracts), [errors](/reference/errors), [native/extension APIs](/reference/extensions-and-native), and [CSS capability matrix](/reference/native-css-capabilities).

For a complete application see [getting started](/getting-started/first-app). For platform restrictions consult [compatibility](/guide/compatibility). Do not derive guaranteed support from an exported symbol name alone.
