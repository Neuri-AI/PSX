## Important differences

- `transform_source` and `transform_file` operate on statically authored Python source; they do not grant unrestricted runtime expression evaluation.
- `compile_template` supports a separately restricted template route. Keep M4A/M4B terms and their security requirements distinct.
- `HeadlessRenderer` records operations in memory, not genuine Qt/Tkinter/Kivy widgets. It is useful for deterministic tests but does not prove native backend parity.
- The exact parameters and return types must be read from the linked definitions before integrating advanced APIs. This page is an export directory, not a substitute for backend-specific behavioral receipts.
