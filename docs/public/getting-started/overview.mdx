In a few minutes, you'll create your first **native desktop window** with Velto. You'll install the framework, write a small Python application, run it, and click a real button. Everything you need is on this page.

We'll use **PySide6 (Qt 6)** for the first example. Velto also integrates with PyQt6, PyQt5, PySide2, Tkinter and Kivy.

## 1. Prepare Python

You need **Python 3.10–3.13**, a terminal and a graphical desktop environment on Windows, macOS or Linux.

Create a folder for your project and an isolated Python environment:

```bash
mkdir my-velto-app
cd my-velto-app
python -m venv .venv
```

Activate it on macOS or Linux:

```bash
source .venv/bin/activate
```

Or on Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

## 2. Install Velto and PySide6

Once Velto is available on PyPI, the installation command will be:

```bash
pip install "velto[pyside6]"
```

<Note>
  **Publication status:** the package is not yet published on PyPI. To try the current source version today, clone the repository and install it with `pip install -e ".[pyside6]"` from the repository root. The commands below use the current `psx` import namespace; the planned `velto` namespace is not implemented yet.
</Note>

For the current source checkout, use:

```bash
git clone https://github.com/Neuri-AI/PSX.git
cd PSX
pip install -e ".[pyside6]"
```

## 3. Create your first application

Create a file named `app.py` in your project folder and paste in this code:

```python
from psx import App, Button, Fragment, Text


def greet() -> None:
    print("Hello from Velto!")


app = App(
    Fragment(
        Text("Hello, Velto!"),
        Button("Click me", on_click=greet),
    ),
    renderer="pyside6",
)

if __name__ == "__main__":
    app.run()
```

This is a **complete native application** using Velto's Python component API. It does not require a browser or a Headless renderer.

## 4. Run it

From the folder containing `app.py`, run:

```bash
python app.py
```

A Qt window should open showing **Hello, Velto!** and a **Click me** button.

Click the button. You should see this in your terminal:

```text
Hello from Velto!
```

Close the window using its usual window controls. You have now created and run a native Python UI with Velto.

## 5. Understand what you wrote

- **`Text("Hello, Velto!")`** describes the text in the window.
- **`Button("Click me", on_click=greet)`** creates a button and connects it to your Python function.
- **`Fragment(...)`** groups multiple elements into one interface tree.
- **`renderer="pyside6"`** tells Velto to use native Qt widgets through PySide6.
- **`app.run()`** starts the application and its event loop.

Try changing the button label or the greeting, then run `python app.py` again to see your change.

## 6. Where does PSX Markup fit in?

Velto also has **PSX Markup**, an HTML/JSX-inspired way to describe the same kind of interface using tags:

```python
from psx import psx

view = psx("""
    <Fragment>
        <Text>Hello, Velto!</Text>
        <Button>Click me</Button>
    </Fragment>
""")
```

This snippet shows the **markup syntax**, not another complete runnable program. Currently, authored PSX Markup uses a static transformation step before Python execution. The working application above uses the Python component API so you can run it immediately without that extra step.

To learn how markup is transformed, and how to use values and event handlers in tags, continue with [PSX Markup](/learn/psx-markup).

## Other supported UI bindings

PySide6 is the default for this tutorial, not the only option.

| Binding | Toolkit | Install extra |
| --- | --- | --- |
| **PySide6** | Qt 6 | `velto[pyside6]` |
| PyQt6 | Qt 6 | `velto[pyqt6]` |
| PyQt5 | Qt 5 | `velto[pyqt5]` |
| PySide2 | Qt 5 | `velto[pyside2]` (Python 3.10 only) |
| Tkinter | Tk | Included with many Python installations |
| Kivy | Kivy | `velto[kivy]` |

These are the intended published-package installation forms; while using a source checkout, replace `velto[...]` with `.[...]` and install from the repository root. Backend support for individual components may vary.

## Troubleshooting

**Python can't import `psx` or `PySide6`:** activate your virtual environment and verify that the installation completed in that environment.

**No window opens:** make sure you're using a graphical desktop session. A server terminal without a display cannot show a Qt window.

**You edited the code but see the old result:** close the running application and run `python app.py` again.
