# Getting started

You should already know how to create a Python virtual environment and run a Python script. You do **not** need to know Qt, Kivy, Tkinter, VNodes or reconciliation.

Begin with [installation](/getting-started/installation), continue to [first app](/getting-started/first-app) and [the Tkinter native window](/getting-started/native-tkinter). The learning section covers components, markup, state, events, conditionals, keyed lists, effects and native layout. Some concept fragments are deliberately non-standalone; the checked-in Headless examples and native Tkinter smoke provide executable entry points.

<Warning>
  The Headless tutorial and Tkinter native smoke have distinct coverage. Follow their individual environment steps and validation receipts; passing Headless does not certify graphical behavior.
</Warning>

In the meantime, [learn the mental model](/concepts/architecture) and [read the component catalog policy](/components/overview).
