Build your first **native desktop application** with Velto in just a few steps.

We'll use **PySide6 (Qt 6)** and PSX Markup to display a simple Hello World window. No previous experience with Velto is required.

## 1. Prepare your environment

You'll need **Python 3.10–3.13**, an Internet connection, and a graphical desktop environment on Windows, macOS, or Linux.

Create a workspace and a virtual environment:

```bash
mkdir my-velto-projects
cd my-velto-projects
python -m venv .venv
```

Activate your environment:

<Tabs>
  <Tab title="macOS / Linux">

    ```bash
    source .venv/bin/activate
    ```

  </Tab>
  <Tab title="Windows PowerShell">

    ```powershell
    .venv\Scripts\Activate.ps1
    ```

  </Tab>
  <Tab title="Windows CMD">

    ```bat
    .venv\Scripts\activate.bat
    ```

  </Tab>
</Tabs>

## 2. Install Velto

Install Velto using pip:

```bash
pip install velto
```

## 3. Create your first application

Use the CLI to generate a new PySide6 project:

```bash
velto init --name my-first-velto-app --framework pyside6
```

Follow the prompts if the CLI asks for additional information.

Once initialization is complete, open your project:

```bash
cd my-first-velto-app
```

<Tip>
  Velto automatically generates the application structure, configuration, resources, and starter code. You don't need to create these files manually.
</Tip>

## 4. Run your application

Start the application:

```bash
velto start
```

Your first native window should appear:

![Native Velto application displaying Hello World](/screenshots/velto-hello-world.png)

## 5. Understand your first application

Open `main.py`. The generated application looks like this:

```python
import sys
from qyro import VeltoContext
from psx import psx

class MyFirstVeltoApp(VeltoContext):
    def render(self):
        return psx("""
            <Flex>
                <Text>Hello, World!</Text>
            </Flex>
        """)

if __name__ == "__main__":
    sys.exit(MyFirstVeltoApp().run())
```

There are only three things you need to understand for now:

- **`VeltoContext`** manages your application's lifecycle.
- **`render()` and `psx()`** describe the interface using PSX Markup.
- **`run()`** starts the native application.

The `<Flex>` component provides a layout, while `<Text>` displays the greeting.

## 6. Make it yours

Change the greeting in `main.py`:

```xml
<Flex>
    <Text>My first Velto application!</Text>
</Flex>
```

Save your changes, close the application, and run it again:

```bash
velto start
```

Your window will now display your updated message.

You've just built and modified your first native Python interface with Velto!
