Velto builds native desktop interfaces with Python and **PSX Markup**. Start with a supported graphical environment and Python **`>=3.10,<3.13.20`**; Python 3.12 is the first-tutorial default.

## Your learning path

1. [Install Velto](/getting-started/installation) from the five current GitHub source repositories. The current `0.1.0` ecosystem is not uniformly published on PyPI.
2. [Create a native application](/getting-started/first-app) using `VeltoContext`, `psx` and `settings/base.json`.
3. [Learn PSX Markup](/learn/psx-markup) for tags and expressions, and [components](/learn/components) for reusable UI.
4. [Add Pydux state](/learn/state-and-events) and understand how the reconciler updates native widgets.
5. [Prepare a distribution](/guide/distribution) only after checking the platform [compatibility matrix](/guide/compatibility).

No browser or HTML DOM is involved. Qyro boots your application, PSX manages markup and native renderers, Cinnamon calculates geometry inside PSX, and Pydux handles shared state.

**How to verify:** the [installed native integration suite](https://github.com/Neuri-AI/Velto/actions/runs/39962860498) runs real PySide6, Tkinter and Kivy application mounts on Linux with Rust and Python Cinnamon. It does not certify every OS/backend combination.
