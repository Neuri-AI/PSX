In a few minutes, you'll create your first **native desktop window** with Velto. You'll install the framework, write a small PSX Markup interface, transform it, and open a real window. Everything you need is on this page.

We'll use **PySide6 (Qt 6)** for the first example. Velto also integrates with PyQt6, PyQt5, PySide2, Tkinter and Kivy.

## 1. Prepare Python

You need **Python 3.10–3.13**, a terminal and a graphical desktop environment on Windows, macOS or Linux.

Create a folder for your project and an isolated Python environment:

```bash
mkdir my-velto-app
cd my-velto-app
python -m venv .venv
```

Activate it on macOS or Linux:

```bash
source .venv/bin/activate
```

Or on Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

## 2. Install Velto and PySide6

Once Velto is available on PyPI, the installation command will be:

```bash
pip install "velto[pyside6]"
```

<Note>
  **Publication status:** the package is not yet published on PyPI. To try the current source version today, clone the repository and install it with `pip install -e ".[pyside6]"` from the repository root. The commands below use the current `psx` import namespace; the planned `velto` namespace is not implemented yet.
</Note>

For the current source checkout, use:

```bash
git clone https://github.com/Neuri-AI/PSX.git
cd PSX
pip install -e ".[pyside6]"
```

## 3. Create your first application with PSX Markup

Create a file named `app.py` in the repository root and paste in this code:

```python
from psx import App, psx

view = psx("""
    <Text>Hello, Velto!</Text>
""")

app = App(view, renderer="pyside6")

if __name__ == "__main__":
    app.run()
```

Notice the interface is defined with **PSX Markup**, using the `<Text>` tag. Python handles the application startup; the UI itself is expressed in markup.

## 4. Transform the markup and run it

The current PSX Markup implementation has a **static transformation step**. Transform your source into runnable Python before launching it:

```bash
python -m psx.markup.transform app.py -o app_generated.py
python app_generated.py
```

A real PySide6 window should open displaying **Hello, Velto!**. Close it with your desktop window controls.

The transformer processes the markup without using unrestricted Python `eval`. It generates Python code that builds Velto's interface representation.

## 5. Understand what you wrote

- **`psx("""...""")`** is where you write the markup.
- **`<Text>Hello, Velto!</Text>`** describes a text element with familiar opening and closing tags.
- **`App(view, renderer="pyside6")`** connects the resulting UI tree to the PySide6 native renderer.
- **`app.run()`** starts the native application.

Try changing the text inside `<Text>`, then run both commands again. You should see your new message in the window.

As you progress, you can nest elements, add attributes, handle events and build more interactive interfaces. See [PSX Markup](/learn/psx-markup) for the syntax and expression rules.

## Other supported UI bindings

PySide6 is the default for this tutorial, not the only option.

| Binding | Toolkit | Install extra |
| --- | --- | --- |
| **PySide6** | Qt 6 | `velto[pyside6]` |
| PyQt6 | Qt 6 | `velto[pyqt6]` |
| PyQt5 | Qt 5 | `velto[pyqt5]` |
| PySide2 | Qt 5 | `velto[pyside2]` (Python 3.10 only) |
| Tkinter | Tk | Included with many Python installations |
| Kivy | Kivy | `velto[kivy]` |

These are the intended published-package installation forms; while using a source checkout, replace `velto[...]` with `.[...]` and install from the repository root. Backend support for individual components may vary.

## Troubleshooting

**Python can't import `psx` or `PySide6`:** activate your virtual environment and verify that the installation completed in that environment.

**No window opens:** make sure you're using a graphical desktop session. A server terminal without a display cannot show a Qt window.

**You edited the code but see the old result:** close the running application and run `python app.py` again.
