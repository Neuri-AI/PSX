# Getting started

You should already know how to create a Python virtual environment and run a Python script. You do **not** need to know Qt, Kivy, Tkinter, VNodes or reconciliation.

The complete hands-on course will be published in G3, after each lesson is independently reproduced from a clean environment. The sequence will cover installation, the first native app, components, markup, state, events, conditionals, keyed lists, effects and native layout.

<Warning>
  No installation or application snippet on this page is advertised as a verified tutorial. Consult the eventual renderer-specific lesson for supported Python versions and exact installation commands.
</Warning>

In the meantime, [learn the mental model](/concepts/architecture) and [read the component catalog policy](/components/overview).
