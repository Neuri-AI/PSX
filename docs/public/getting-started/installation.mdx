You'll install Velto and **PySide6**, the Qt binding used in our first tutorial. By the end, your computer will be ready to open a native desktop window.

## Before you begin

You'll need **Python 3.10–3.13**, Git, a terminal, and a graphical desktop session on Windows, macOS, or Linux. The commands below install the current project source so they match the examples in this documentation.

## 1. Get the project

```bash
git clone https://github.com/Neuri-AI/PSX.git
cd PSX
```

## 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on **macOS or Linux**:

```bash
source .venv/bin/activate
```

Or on **Windows PowerShell**:

```powershell
.venv\Scripts\Activate.ps1
```

A virtual environment keeps your project's Python dependencies separate from other applications.

## 3. Install Velto with PySide6

```bash
pip install --upgrade pip
pip install -e ".[pyside6]"
```

The `[pyside6]` extra installs the Qt binding needed for the first window. You can install a different supported binding later.

## 4. Verify the installation

```bash
python -c "from psx import App, Text; from PySide6.QtWidgets import QApplication; print('Velto and PySide6 are ready!')"
```

Expected output:

```text
Velto and PySide6 are ready!
```

<Note>
  The current source distribution is called `velto`, while its Python import namespace is still `psx`. The intended future import style is `from velto import ...`; until that migration is implemented, follow the working imports in these examples.
</Note>

## Other supported renderers

The [Getting started overview](/getting-started/overview) lists all supported UI toolkits: **PySide6, PySide2, PyQt5, PyQt6, Tkinter, and Kivy**. This guide uses PySide6 so you can follow one consistent path from installation to your first window.

## Troubleshooting

If `python` is not found, check your Python installation and try `python3` where appropriate. If imports fail, make sure your virtual environment is active and rerun the install command from the repository root. On Linux, opening Qt windows requires a working graphical display and the platform libraries needed by Qt.
