## Requirements

Use a graphical desktop on Linux, Windows or macOS; Git; and **Python `>=3.10,<3.13.20`**. Python 3.12 is a practical starting point for the current verified native integration.

The first-party `0.1.0` packages are **not all published to PyPI**. Install the project sources instead of assuming `pip install velto` resolves to this ecosystem.

## Create an environment

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
```

On Windows activate with `.venv\Scripts\activate`. Conda is also supported as an environment manager: `conda create -n velto-dev python=3.12` followed by `conda activate velto-dev`.

## Install from GitHub

```bash
git clone --branch develop https://github.com/Neuri-AI/PSX.git
git clone --branch main https://github.com/Neuri-AI/Pydux.git
git clone --branch release https://github.com/Neuri-AI/qyro.git
git clone --branch release https://github.com/Neuri-AI/Velto-CLI.git
git clone --branch main https://github.com/Neuri-AI/Velto.git

python -m pip install -e ./Pydux
python -m pip install -e "./PSX[pyside6]"
python -m pip install -e ./qyro
python -m pip install -e ./Velto-CLI
python -m pip install -e "./Velto[pyside6]"
python -m pip check
velto --help
```

These commands use the currently integrated source branches. To reproduce a specific CI run, pin the commit SHAs from its artifacts rather than moving branches. The [installed-wheel CI](https://github.com/Neuri-AI/Velto/actions/runs/39962860498) verifies independent installations for Python 3.10–3.13 and native PySide6/Tkinter/Kivy mounting on Linux 3.12.
