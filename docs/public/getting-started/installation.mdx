You can install Velto directly into an existing Python project or use **Velto CLI** to generate a complete application. The CLI is optional.

## Requirements

Velto supports **Python 3.10–3.13** on Windows, macOS, and Linux.

Before installing, make sure you have:

- Python 3.10–3.13
- pip, Python's package manager
- A terminal
- A graphical desktop environment to run native applications

We recommend using a virtual environment to keep your project dependencies isolated.

Create one in your project directory:

```bash
python -m venv .venv
```

Activate it for your operating system:

<Tabs>
  <Tab title="macOS / Linux">

    ```bash
    source .venv/bin/activate
    ```

  </Tab>
  <Tab title="Windows PowerShell">

    ```powershell
    .venv\Scripts\Activate.ps1
    ```

  </Tab>
  <Tab title="Windows CMD">

    ```bat
    .venv\Scripts\activate.bat
    ```

  </Tab>
</Tabs>

## Install Velto

Install the core framework using pip:

```bash
python -m pip install velto
```

This installs Velto without an optional native UI backend.

If you already have a Python project, you can install Velto directly into its existing environment. You don't need to generate a new project or install Velto CLI.

<Note>
  The package is distributed as `velto`, but its current Python import namespace is `psx`.
</Note>

## Choose a UI backend

Velto supports several native UI backends. Install the dependency group corresponding to the framework you want to use.

| Backend | Installation |
| --- | --- |
| PySide6 | `pip install "velto[pyside6]"` |
| PyQt6 | `pip install "velto[pyqt6]"` |
| PyQt5 | `pip install "velto[pyqt5]"` |
| PySide2 | `pip install "velto[pyside2]"` |
| Kivy | `pip install "velto[kivy]"` |
| Tkinter | `pip install velto` |

For example, to install Velto with PySide6:

```bash
python -m pip install "velto[pyside6]"
```

<Tip>
  We recommend **PySide6** if you're new to Velto. It's the backend used in the Getting Started tutorial.
</Tip>

### Backend compatibility

Backend compatibility depends on the Python version and the availability of native dependencies.

| Backend | Python compatibility | Notes |
| --- | --- | --- |
| PySide6 | 3.10–3.13 | Qt 6 |
| PyQt6 | 3.10–3.13 | Qt 6 |
| PyQt5 | 3.10–3.13 | Qt 5 |
| PySide2 | 3.10 | Qt 5; restricted to Python below 3.11 |
| Kivy | Depends on the installed release | Tested with Kivy 2.3.1 |
| Tkinter | Depends on your Python distribution | No Velto extra required |

<Note>
  Velto has been tested with **Kivy 2.3.1**. Compatibility with other Kivy versions has not been verified.
</Note>

<Warning>
  PySide2 is restricted to Python 3.10 by the current dependency configuration. Use a compatible Python environment if your application requires PySide2.
</Warning>

### Installing Tkinter

Tkinter is included with many Python distributions, so you don't need a separate Velto extra.

Install Velto normally:

```bash
python -m pip install velto
```

Check whether Tkinter is available:

```bash
python -m tkinter
```

If Tkinter is missing, you may need to install it through your operating system's package manager.

### Install multiple backends

You can install more than one backend in the same environment:

```bash
python -m pip install "velto[pyside6,pyqt6,kivy]"
```

You only need the backends your application actually uses.

## Optional integrations

Velto provides additional dependency groups for other tools and development workflows.

| Extra | Dependency | Purpose |
| --- | --- | --- |
| `pydux` | `pydux` | State management |
| `qyro` | `qyro-engine` | Application runtime integration |
| `dev` | `pytest`, `build`, `ruff` | Development and testing |

### Pydux

Install the Pydux integration dependencies:

```bash
python -m pip install "velto[pydux]"
```

### Qyro

Install the Qyro runtime integration dependencies:

```bash
python -m pip install "velto[qyro]"
```

### Development tools

If you're contributing to Velto or running its test suite, install the development dependencies:

```bash
python -m pip install "velto[dev]"
```

### Combine optional dependencies

You can combine backend and integration extras in one command:

```bash
python -m pip install "velto[pyside6,pydux,qyro]"
```

This installs Velto with PySide6, Pydux, and the Qyro runtime dependencies.

<Note>
  Installing an optional dependency makes it available to your application. It does not automatically configure or activate every integration.
</Note>

## Install from GitHub

You can install Velto directly from its GitHub repository.

### Install the development version

To install from the `develop` branch with PySide6:

```bash
python -m pip install "velto[pyside6] @ git+https://github.com/Neuri-AI/PSX.git@develop"
```

<Warning>
  The `develop` branch may contain unreleased changes. For reproducible installations, prefer a tagged release or a specific commit.
</Warning>

### Install in editable mode

If you want to contribute to Velto or modify its source code, clone the repository:

```bash
git clone https://github.com/Neuri-AI/PSX.git
cd PSX
```

Switch to the development branch if needed:

```bash
git switch develop
```

Install the package in editable mode:

```bash
python -m pip install -e ".[pyside6,dev]"
```

Editable mode allows Python source changes in your checkout to be reflected in the installed package without reinstalling it after every edit.

## Velto CLI (optional)

**Velto CLI is not required to install or use Velto.**

It provides commands for generating application projects, preparing their configuration, and running development workflows.

If you prefer a ready-made project structure, install the CLI separately:

```bash
python -m pip install velto-cli
```

You can then generate a project using the CLI's `velto` command:

```bash
velto init --name my-first-velto-app --framework pyside6
```

Navigate into your new project:

```bash
cd my-first-velto-app
```

Start the application:

```bash
velto start
```

For a complete walkthrough, see [Getting started](/getting-started/overview).

## Verify your installation

Once Velto is installed, verify that Python can import it:

```bash
python -c "import psx; print('Velto installed successfully!')"
```

Expected output:

```text
Velto installed successfully!
```

If you installed PySide6, you can also verify the backend:

```bash
python -c "from PySide6.QtWidgets import QApplication; print('PySide6 is ready!')"
```

Expected output:

```text
PySide6 is ready!
```

These checks confirm that the packages can be imported. They don't launch a native application.

You can also inspect your installed version:

```bash
python -m pip show velto
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Unsupported Python version">

    Check your Python version:

    ```bash
    python --version
    ```

    Velto currently supports Python 3.10–3.13. If you're using another version, create a virtual environment with a compatible Python interpreter.

  </Accordion>
  <Accordion title="No matching distribution found">

    This may indicate that your Python version, operating system, or architecture isn't supported by the requested package.

    Verify your Python version and the compatibility of your selected backend.

  </Accordion>
  <Accordion title="ModuleNotFoundError: psx">

    Verify that Velto is installed in your active environment:

    ```bash
    python -m pip show velto
    ```

    If the package isn't installed, run:

    ```bash
    python -m pip install velto
    ```

  </Accordion>
  <Accordion title="Missing native UI backend">

    Install the extra for your selected backend. For example:

    ```bash
    python -m pip install "velto[pyside6]"
    ```

    Restart your application after installation.

  </Accordion>
  <Accordion title="Tkinter is unavailable">

    Tkinter may be distributed separately by your operating system.

    Check whether it's available:

    ```bash
    python -m tkinter
    ```

    If it isn't available, consult your Python distribution's installation instructions.

  </Accordion>
  <Accordion title="Native window doesn't open">

    Make sure you're running your application in a graphical desktop environment.

    Some Linux environments may require additional system libraries or display-server configuration for Qt or Kivy.

  </Accordion>
</AccordionGroup>
