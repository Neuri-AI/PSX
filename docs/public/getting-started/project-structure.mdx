---
title: "Project structure"
description: "Understand the files used by Qyro and the Velto CLI."
---

Velto CLI can scaffold a complete project with `velto init --framework pyside6`. The precise generated files depend on the selected template; do not assume each template has an identical tree.

A minimal conceptually useful layout is:

```text
my-app/
├── main.py
├── pyproject.toml
├── settings/
│   └── base.json
└── resources/
```

**`main.py`** contains a `VeltoContext` subclass whose `render()` returns PSX Markup. **`settings/base.json`** specifies the `app_name`, the `framework` (for example `pyside6`) and the `window` dimensions. **`resources/`** stores application assets. **`pyproject.toml`** identifies the project and is required by certain CLI packaging guards.

The development command is `velto start`. The distribution commands are `velto build` and `velto bundle`. In frozen projects, Qyro can load settings and assets from the protected `.pak`; never assume the executable's working directory equals the original source directory.

**How to verify:** [packaged executable suite](https://github.com/Neuri-AI/Velto/actions/runs/39967824985) starts frozen projects using a real settings file and a protected asset extracted from a release archive.
