title: "Your first application"
description: "Create and start a native PySide6 application using PSX Markup."
---

The [installation guide](/getting-started/installation) installs Velto and PySide6. A Velto application is a Python class extending **`VeltoContext`** and implementing **`render()`**.

## Project files

Create `settings/base.json`:

```json
{
  "app_name": "Hello Velto",
  "framework": "pyside6",
  "window": { "width": 640, "height": 400 }
}
```

Create `main.py`:

```python
from velto import VeltoContext
from velto.ui import psx

class HelloApp(VeltoContext):
    def render(self):
        return psx("""
            <Flex direction="column" gap="12px">
                <Text value="Hello, Velto!" />
            </Flex>
        """)

if __name__ == "__main__":
    HelloApp().run()
```

The `render()` method returns PSX Markup, not an HTML page. `Flex` produces a native layout and `Text` produces a native-compatible text control. Qyro reads `settings/base.json`; this example needs **no** `<Window>` tag.

Run from the project root:

```bash
velto start
```

The CLI runs the project with its configured native backend. Use `velto start --no-hot-reload` to disable development reload. The exact CI-verified application path includes Qyro settings bootstrap, PSX Markup, both Cinnamon engines, and native renderer lifetimes; [see the functional receipt](https://github.com/Neuri-AI/Velto/actions/runs/39962860498).

<Note>
The full CLI-generated template may include additional settings, resources and dependencies. This intentionally minimal file tree is for learning the core application contract; create an official scaffold with `velto init --framework pyside6` if you want a complete generated project.
</Note>
