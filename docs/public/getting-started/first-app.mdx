Let's open your first **real desktop window** with Velto.

We'll use **PySide6**, a Python binding for Qt 6. The example creates a window containing text, a button, and a native Qt label. You can click the button and close the window normally.

## 1. Install the dependencies

Complete [Install Velto](/getting-started/installation) first. In particular, install the PySide6 extra:

```bash
pip install -e ".[pyside6]"
```

## 2. Run the application

From the root of the cloned repository:

```bash
python examples/f5_5_native_gallery/qt_app.py
```

A **native Qt window** should appear. It contains the text **Velto + PySide6**, a button labeled **Hello Qt**, and a Qt label displaying **Native QLabel via Velto**.

Click **Hello Qt**. The application prints `Qt clicked` in the terminal. Close the window using your desktop's close control.

## 3. Understand the code

The complete, runnable source is [qt_app.py on GitHub](https://github.com/Neuri-AI/PSX/blob/develop/examples/f5_5_native_gallery/qt_app.py). The central part is:

```python
from PySide6.QtWidgets import QLabel
from psx import App, Text, Button, Fragment, Native

app = App(
    Fragment(
        Text("Velto + PySide6"),
        Button("Hello Qt", on_click=lambda: print("Qt clicked")),
        Native(QLabel, props={"text": "Native QLabel via Velto"}),
    ),
    renderer="pyside6",
)

app.run()
```

- **`App(..., renderer="pyside6")`** selects the native Qt renderer.
- **`Fragment`** groups the three elements.
- **`Text`** creates a portable text element.
- **`Button`** creates a clickable control; `on_click` is its event handler.
- **`Native(QLabel, ...)`** demonstrates embedding a toolkit-specific Qt widget when you need one.
- **`app.run()`** starts the application and keeps its window open until it is closed.

This is a **Python component API** example. Velto also supports **PSX Markup**, its HTML/JSX-inspired syntax. You'll learn how to express UI structure with markup in [PSX Markup](/learn/psx-markup), including its source transformation step. We are using the existing, runnable native example here so your first experience is a real window rather than a mockup.

## 4. Try changing something

Open `examples/f5_5_native_gallery/qt_app.py` in your editor. Change the text `Velto + PySide6` to a greeting of your choice. Save the file, close the existing window if it is still open, and run the command again.

You've just modified a native Python interface using Velto.

## Troubleshooting

**No window appears:** make sure you're running in a graphical desktop session rather than a headless terminal or CI runner.

**`ModuleNotFoundError: PySide6`:** activate the environment from installation and run `pip install -e ".[pyside6]"` again.

**Qt platform plugin error on Linux:** verify that your desktop display and required Qt platform libraries are available.
