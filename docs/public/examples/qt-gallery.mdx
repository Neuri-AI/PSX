# A native PySide6 application

The runnable project is [qt_app.py](https://github.com/Neuri-AI/PSX/blob/df5eff3e9fd8d2af0775fd1576f9c76ac66ef619/examples/f5_5_native_gallery/qt_app.py). It mounts portable `Text` and `Button` controls, plus a real backend-specific `QLabel` through `Native(QLabel, props={...})`, using the **native PySide6 renderer**. It does not use a browser.

## Prerequisites and installation

Use Python 3.10–3.13, Git and a working Qt-capable desktop. Clone the actual source and install the optional PySide6 binding:

```bash
git clone https://github.com/Neuri-AI/PSX.git
cd PSX
git checkout df5eff3e9fd8d2af0775fd1576f9c76ac66ef619
python -m venv .venv
```

Activate the venv using `source .venv/bin/activate` on macOS/Linux or `.venv\Scripts\Activate.ps1` in PowerShell.

```bash
python -m pip install -e ".[pyside6]"
python examples/f5_5_native_gallery/qt_app.py
```

The repository project files are:

```text
examples/f5_5_native_gallery/
├── app.py
└── qt_app.py
```

No separate settings file or markup transform is used. The example explicitly selects `renderer="pyside6"` and produces three native controls; clicking the button prints `Qt clicked` to the terminal.

## Run the automated native smoke

On a Linux runner with Qt offscreen support:

```bash
QT_QPA_PLATFORM=offscreen python examples/f5_5_native_gallery/qt_app.py --smoke
```

Expected output is `PySide6 native mount: PASS`. The `Native` declaration owns its `QLabel` and applies its text via the Qt adapter; this is a deliberately backend-specific escape hatch. This mounts and tears down real Qt widgets but does not visually inspect the GUI. Avoid treating an offscreen smoke as evidence for macOS or Windows. If the `xcb` platform plugin fails, use the offscreen mode for smoke testing or install required Linux graphical libraries for an interactive session.
