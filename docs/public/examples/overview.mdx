The PSX repository includes checked-in examples for several backends. These source projects predate the current consolidated Velto facade tutorials, so **their pinned source SHAs are part of each example's reproduction instructions**. Do not silently swap in another framework version or assume the examples are universal backend smoke tests.

- [Task board](/examples/task-board): hooks, keys and Headless behavior, with a separate native PySide6 mount.
- [Tkinter gallery](/examples/native-gallery): actual native controls and event-loop startup.
- [PySide6 gallery](/examples/qt-gallery): real Qt controls and a backend-specific `Native` widget.
- [Kivy gallery](/examples/kivy-gallery): actual Kivy widgets and an Xvfb-backed Linux smoke.

Read each page's requirements, source commit, expected behavior and troubleshooting before running it. A Headless test does not certify native widgets, and a Linux native smoke does not certify signed Windows or macOS releases.

New applications should start from [Velto's current GitHub installation](/getting-started/installation) and use [PSX Markup](/learn/psx-markup). Verified current integrated Qyro/PSX/Cinnamon/Pydux application behavior is documented separately in the [cross-package CI](https://github.com/Neuri-AI/Velto/actions/runs/39962860498).
