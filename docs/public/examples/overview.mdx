# Reproducible applications

An example is **runnable** only when its repository directory includes the full project, installation instructions, settings, entry point, commands, tests, expected behavior and evidence for the renderer it claims to support.

Applications and screenshots are planned for G5. No screenshots or sample output are represented here as tested. Headless test success does not imply native renderer success.

Before trying an application, consult its compatibility matrix and pinned commit SHA. Return to [Getting started](/getting-started/overview).
