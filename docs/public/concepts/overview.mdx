title: "Concepts"
description: "The essential terms of Velto's architecture."
---

**PSX Markup** describes native UI structure using tags, attributes and expressions. **VNode** is PSX's in-memory interface representation, and the **reconciler** updates native widgets without requiring the application window to be recreated on every compatible state change.

**Cinnamon** is PSX's geometry engine, running in Rust where installed and using a Python fallback. **Qyro Engine** manages the application context, configuration and resources. **Pydux** provides state, actions and selectors. **Velto CLI** manages project creation and development, building and bundling.

The public **`velto` facade** exposes the original Qyro, PSX and Pydux interfaces. Velto is a native UI framework, **not an HTML/browser framework**.
