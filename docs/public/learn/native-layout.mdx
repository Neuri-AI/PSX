# Native layout with Cinnamon

Cinnamon is Velto's renderer-neutral layout authority. Renderer adapters measure and mount actual backend widgets but do not replace the layout calculation with an independent browser engine. The native renderer and viewport constraints are essential inputs when a layout primitive requires geometry.

```python
from psx import Flex, Text

node = Flex(Text("Item"), direction="column", gap=12)
```

This is a **VNode declaration fragment**, not a standalone mounted application. In particular, mounting `Flex` with Headless **without explicit Cinnamon/SFLE viewport constraints raises `RendererCapabilityError`**. The [Hello World](/getting-started/first-app) example deliberately uses `Fragment` for a geometry-free Headless lesson. Responsive `Grid`/ `GridItem` require their documented structural child policies and native geometry support; a registry entry alone does not guarantee availability.
