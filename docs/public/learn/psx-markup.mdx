**PSX Markup** is Velto's supported authoring syntax for native interfaces. Tags form a tree of VNodes. They do not create browser DOM nodes.

## Tags and nested content

```python
from velto.ui import psx

node = psx("""
    <Flex direction="column" gap="12px">
        <Text value="Welcome" />
        <Button text="Continue" />
    </Flex>
""")
```

Quoted attributes, such as `gap="12px"`, are literals. Braces represent an expression or a reference, **not** inferred conversion of quoted strings to Python numbers.

## Values in a component

The installed integration test exercises this explicit-scope form:

```python
from velto.ui import psx

name = "World"
view = psx('<Text value={greeting} />', scope={"greeting": f"Hello, {name}"})
```

The `scope` argument is for explicit or generated name resolution. In normal project source, use the supported authored expression syntax and let the development toolchain process the file. Do not use the obsolete `psx.markup.transform` command or `eval`.

## Identity and updates

When markup is returned by a component and state changes, the reconciler compares its VNodes and updates native widgets. Stable `key` values matter for lists. Read [lists and keys](/learn/lists-and-keys) and [state](/learn/state-and-events).

**Verify:** the [integration CI](https://github.com/Neuri-AI/Velto/actions/runs/39962860498) mounts markup on PySide6, Tkinter and Kivy. It does not assert that every possible JavaScript-like expression is supported.
