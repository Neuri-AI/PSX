---
title: "Effects and cleanup"
description: "Run a side effect after commit and release it on unmount."
---

A PSX `use_effect` hook schedules work after a component is committed. An effect may return a zero-argument cleanup function, which the runtime invokes when appropriate before re-running the effect or releasing the component.

```python
from velto.ui import Text, component, use_effect

@component
def ConnectionStatus():
    def subscribe():
        print("mounted")
        return lambda: print("unmounted")
    use_effect(subscribe, [])
    return Text("Connected")
```

This fragment illustrates lifecycle shape only. Replace prints with a real subscription and cleanup in your application. Never call hooks conditionally or inside changing loops.

**Verification:** component and hook lifecycle behaviors are covered in PSX's runtime tests; the [integrated native suite](https://github.com/Neuri-AI/Velto/actions/runs/39962860498) verifies Pydux provider teardown, not every possible effect side effect.
