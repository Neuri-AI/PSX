# Effects and cleanup

The `use_effect` hook schedules a callback after a UI commit. It optionally returns a zero-argument cleanup function, called before the next applicable effect and during unmount.

```python
from psx import Text, component, use_effect

@component
def Observed():
    def setup():
        print("mounted")
        return lambda: print("unmounted")
    use_effect(setup, [])
    return Text("Effect example")
```

This is an **illustrative component fragment**, not a full runnable program. An empty dependency sequence keeps the effect stable when the dependencies do not change. Do not perform `use_effect` inside loops or conditionals. See [state and events](/learn/state-and-events) for an executable hook example.
