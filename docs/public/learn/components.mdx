# Components

A **component** is a reusable function returning a VNode. `@component` wraps the function so the reconciler can track its identity and hooks. A **portable component** such as `Text` or `Button` has a backend-independent contract, but support for individual properties still depends on validated contracts and native receipts.

```python
from psx import Fragment, Text, component

@component
def Greeting():
    return Fragment(Text("Welcome"))
```

This code is an **illustrative fragment**; the runnable project is [Hello World](/getting-started/first-app). The real `Text` constructor accepts a value and optional formatting arguments. `Fragment` groups children but does not calculate layout geometry. Components must return a valid VNode.
