Velto supports recommended **lowercase HTML-like elements** as well as integrated components such as `Flex`, `Grid`, `GridItem`, `Scroll` and `Native`.

## Layout components

```python
from velto.ui import psx

view = psx("""
    <Flex direction="column" gap="16px">
        <Text value="Dashboard" />
        <Scroll>
            <Text value="Scrollable content" />
        </Scroll>
    </Flex>
""")
```

`Flex` arranges children; `Grid` and `GridItem` support the framework's 12-column responsive grid. `Scroll` delegates scroll interaction to an actual toolkit adapter. For standard controls, prefer the HTML-like tags appropriate to the desired markup behavior, and consult the [component contracts](/reference/component-contracts) for supported properties.

## Your own components

`@component` marks a Python component function whose VNode identity and hooks are managed by the reconciler:

```python
from velto.ui import component, Text

@component
def Greeting():
    return Text("Hello")
```

This is a component fragment, not a complete application. You can return it as part of a mounted UI tree. Read [native embedding](/guide/native-integration) for the `Native` boundary and [hooks](/learn/effects) for effects and cleanup.

**Verify:** inspect the specific renderer's supported properties and test with the backend you intend to ship. An exported component name alone does not prove identical backend capabilities.
