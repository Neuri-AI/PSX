# Lists and stable keys

For a list of values, create one VNode per item with a stable `key`. Keys are local to siblings and may be strings or integers, but not booleans. Duplicate sibling keys are rejected by reconciliation.

```python
from psx import Fragment, Text

labels = ["Alpha", "Beta"]
node = Fragment(*(Text(label, key=label) for label in labels))
```

This is a **standalone VNode construction fragment**, not a mounted application. A real interactive example is linked from [first app](/getting-started/first-app). Use durable IDs from the underlying data for keys; do not use changing positions when elements can be reordered. A changed key intentionally allows subtree identity to change.
