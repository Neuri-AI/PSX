---
title: "Conditional rendering"
description: "Choose a subtree without breaking hook order."
---

A component can select content based on state. Hooks such as `use_state`, `use_selector` and `use_effect` must be called in the same order during every render.

```python
from velto.ui import Text, component, use_state

@component
def Status():
    online, set_online = use_state(False)
    return Text("Online" if online else "Offline")
```

This is an **illustrative component fragment**, not a standalone app. Its setter is unused. Attach the component to a mounted `VeltoContext` application and update its state from an event handler.

PSX Markup additionally supports authored conditional expressions under its compiler contract; that does not mean arbitrary Python code is evaluated inside braces. Read [PSX Markup](/learn/psx-markup) and [state](/learn/state-and-events).
