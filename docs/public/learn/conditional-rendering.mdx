# Conditional rendering

For ordinary Python components, choose a value or subtree with normal Python conditional expressions. **Do not call hooks conditionally**: they must appear in the same order on every render.

```python
from psx import Text, component, use_state

@component
def Status():
    online, set_online = use_state(False)
    return Text("Online" if online else "Offline")
```

This is an **illustrative fragment**, not a standalone application: the setter is deliberately unused. The full mounted, tested model of state updates appears in [state and events](/learn/state-and-events). The static expressive markup compiler separately supports its documented restricted conditional expressions; do not assume arbitrary Python execution inside template braces.
