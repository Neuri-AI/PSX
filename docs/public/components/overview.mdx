# Component catalog

A component is an interface building block. Some accept text or child components; others restrict children. Every component reference will list its real properties and defaults, events, child policy, and backend-specific behavior.

The source of truth is the component registry and its contracts in the current `develop` branch, not HTML attributes or React conventions.

The detailed catalog is part of G4. Until then, **do not assume** that an HTML attribute or event name works in Velto. Read [How Velto works](/concepts/architecture) for the rendering model.
