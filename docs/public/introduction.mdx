Velto is a Python framework for native desktop user interfaces. **PSX Markup** is the official way to describe UI structure with nested tags and Python expressions. It resembles HTML or JSX, but the final interface is rendered by a native UI toolkit; no browser or HTML DOM is involved.

## One interface, separate responsibilities

- **PSX** parses markup, creates VNodes, reconciles updates and owns the renderer adapters.
- **Cinnamon**, inside PSX, computes layout. Rust is the primary engine and Python is a fallback.
- **Qyro Engine** supplies `VeltoContext`, application configuration, resources and execution lifecycle.
- **Pydux** supplies state, stores and selectors.
- **Velto CLI** creates, starts, builds and bundles desktop projects.
- The **`velto` facade** exposes those APIs without introducing wrapper objects.

Read [installation](/getting-started/installation), then [your first application](/getting-started/first-app). The platform and Python restrictions in [compatibility](/guide/compatibility) describe measured coverage rather than promising that every renderer supports every feature.
